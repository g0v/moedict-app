# 萌典 7.1.1

Date: 2026-09-14
Upstream: `15490341` → `8e7ad8c7` (g0v/moedict.tw)
Platforms: Android (7.0.6 → 7.1.1, versionCode 70015; R8 beta build 70016)

## 版本说明

内容与 7.1.0 相同（见 `7.1.0.md`），另含上游偏好设置面板堆叠与下拉关闭修正（moedict.tw #174，已随线上版本部署）。

versionCode 取 70015 而非 70014：70014 的 AAB 已于 2026-09-14 上传至 Play 管理中心应用包库但未发布，Play 要求 versionCode 全局唯一，故递增重打。

versionCode 70016（2026-09-15 beta）：AGP 9.0 + R8（minifyEnabled、shrinkResources）建置，內容同 7.1.1。

## Store Changelog, zh-TW

整合 moedict.tw 半年來的內容與介面更新：
- 多音字改依教育部「多音排序」，「鳥」現以 ㄋㄧㄠˇ 為首音
- 錄音改依讀音綁定，修正 82 組錯誤對應
- 新增客語部首檢索與兩岸辭典詞彙對照表
- 台語：又音異讀、整詞羅馬字查詢，補齊「芭蕾」「監理」條目
- 國語／兩岸：搜尋框可直接以漢語拼音查詞
- 筆順動畫新增暫停／逐畫控制與速度設定
- 深色模式與字級偏好可於設定切換
- 筆順與語音資源遷移至 Cloudflare R2
- 修正罕用字圖片缺字與多項版面問題
