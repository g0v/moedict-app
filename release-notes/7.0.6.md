# 萌典 7.0.6

Date: 2026-05-18
Upstream: `moedict.tw` `48196f43f` -> `56a0620f6`

## Store Changelog, zh-TW

更新至最新 moedict.tw 介面與離線內容。

- Android 版鎖定 WebView 字級為 100%，避免系統字級設定過大時導航列被壓板、偏好設定按鈕消失。
- 手機查詢頁在輸入搜尋字詞後才下移內容，避免自動聯想浮層遮住結果，同時保留空白搜尋框時的緊湊版面；此項回應 Google Play 使用者回報。
- 搜尋框新增返回與清除按鈕，並保留舊版「包含」搜尋清單；同步微調手機版下拉選單層級。
- 改善行動版搜尋與版面回歸測試，讓離線 App 和網站行為更一致。

## Store Changelog, English

Updated the offline app to the latest moedict.tw interface and bundled content.

- Android: locked the WebView text zoom to 100% so a large system font size no longer overlaps the navbar or hides the preferences button.
- Mobile dictionary content now moves down only after a search term is entered, keeping the empty search layout compact while preventing autocomplete results from covering entries. Prompted by Google Play feedback.
- Added back and clear controls to the search box while preserving the legacy contains-search list, and adjusted the mobile dropdown stacking order.
- Improved mobile search and layout regression coverage so the offline app stays aligned with the website.
