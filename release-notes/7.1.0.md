# 萌典 7.1.0

Date: 2026-08-11
Upstream: `182e26bb` → `8d99b6d8` (g0v/moedict.tw)
Platforms: Android (7.0.9 → 7.1.0, versionCode 70014), iOS (7.0.9 → 7.1.0, build 14), macOS (7.0.8 → 7.1.0, build 14)

## Store Changelog, zh-TW

整合 moedict.tw 半年來的內容與介面更新：兩岸對照表、台語又音與整詞羅馬字查詢、筆順／語音改走 Cloudflare R2，以及深色模式與筆順速度等偏好設定。本版另同步教育部「多音排序」與錄音綁定修正，並補完罕用字圖片與筆順控制。

- 多音字改依教育部「多音排序」呈現；最明顯的例子是「鳥」現以 ㄋㄧㄠˇ（鳥）為首音，不再先出現 ㄉㄧㄠˇ。
- 錄音改依讀音綁定，修正 82 組錯誤對應（例如「調配」的 ㄊㄧㄠˊ 讀音不再播放 ㄉㄧㄠˋ 的錄音）。
- 罕用字圖片顯示修正：補完 CNS 全字庫字型，含 U+301F7–U+3303C 一段先前顯示為方框的字。
- 筆順動畫新增暫停／下一畫控制，可逐步檢視每一筆。
- 新增兩岸辭典詞彙對照表，便於一次比對兩岸用語差異。
- 台語：顯示又音異讀、真詞目優先排序、整詞羅馬字查詢（如 `binatsai`），並修正標題注音與韻母對齊。
- 國語／兩岸：新增漢語拼音本地索引，搜尋框可直接以拼音查詞。
- 字詞紀錄簿歷史列表可直接收藏／取消收藏。
- 筆順動畫與語音資源由 Rackspace CDN 遷移至 Cloudflare R2；筆順按鈕在無資料時會停用，並可在設定中調整播放速度。
- 深色模式與字級偏好可於設定切換；關於頁補充 API 串接說明。
- 修正兩岸辭典大陸音顯示錯亂、搜尋結果標題字型與 PUA 異體字頭字顯示。
- Android 目標 API 升至 36（Android 16）。

## Store Changelog, English

Bundles six months of moedict.tw content and UI updates: cross-strait term comparisons, Taiwanese alternate readings and whole-word romanization lookup, stroke/audio assets moved to Cloudflare R2, plus dark-mode and stroke-speed preferences. This build also ships the Ministry of Education’s preferred heteronym order, audio-identity fixes, fuller rare-character rendering, and stroke-step controls.

- Polyphonic entries now follow the MOE preferred-reading order; most visibly, 鳥 leads with ㄋㄧㄠˇ (bird) instead of ㄉㄧㄠˇ.
- Audio clips are bound by reading identity, correcting 82 mismatched attachments (for example, 調配’s ㄊㄧㄠˊ reading no longer plays the ㄉㄧㄠˋ clip).
- Rare-character images no longer show as empty boxes for the CNS coverage gap through U+301F7–U+3303C.
- Stroke-order animation gains pause and next-stroke controls for step-by-step review.
- New cross-strait term comparison table for side-by-side vocabulary differences.
- Taiwanese: alternate readings (又音), head-entry-first ordering, whole-word romanization lookup (e.g. `binatsai`), and corrected title-zhuyin / rime alignment.
- Mandarin / Cross-Strait: local Hanyu-pinyin indexes so the search box accepts pinyin queries.
- History list in the notebook now has an inline star toggle.
- Stroke-order animation and audio assets migrated from Rackspace CDN to Cloudflare R2; the stroke button is disabled when data is missing, and playback speed is configurable.
- Dark mode and font-size preferences are available in Settings; the About page now documents the public API.
- Fixed Cross-Strait mainland-pronunciation layout, search-result title fonts, and plane-15 PUA variant headwords.
- Android target API raised to 36 (Android 16).
