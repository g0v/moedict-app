# 萌典 7.1.3

Date: 2026-11-24
Upstream: `38cd39b7` → `a65461e3` (g0v/moedict.tw)
Platforms: Android 7.1.3 (versionCode 70018), iOS 7.1.3 (build 18)

## Changes

- Offline apps bundle the About-page guide images (#186, PR #27 by @bestian).
- iOS: swipe from the left edge to go back through visited entries (PR #28).
- Offline favicon points at the bundled `/icon.png`, removing a WebView 404 (PR #28).
- Upstream moedict.tw #187: history keeps only real headwords; the offline build no longer requests a missing stylesheet.
- Upstream moedict.tw #188 (mobile QA fixes):
  - Taiwanese romanization search accepts tone marks.
  - Share produces a moedict.tw permalink instead of a local app URL.
  - When a glyph image fails to load offline, a text glyph is shown instead.
  - The starred-words download and print-card buttons, which cannot work offline, are hidden in the app.
  - About-page inline code wraps on narrow screens.
  - Radical history is recorded only when the radical has rows.
